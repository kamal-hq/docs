# Documentation Portal Rules

- **Dual Hosting Compatibility**: Keep routing and asset paths compatible with both Vercel (`/`) and GitHub Pages (`/<repo>/` or `*.github.io`). Use `import.meta.env.BASE_URL` helpers in `src/App.tsx` and `BASE_PATH` in `vite.config.ts`.
- **Data Separation**:
  - Hand-curated projects live in `manualProjects` inside `src/data/projects.ts`, and hand-crafted documentation pages live in `projectDocsRegistry` inside `src/data/docs.ts`.
  - Automated GitHub sync outputs belong strictly in `src/data/synced/projects.json` and `src/data/synced/docs.json` (generated by `scripts/sync-github-docs.mjs`). Never overwrite manual entries during sync.
- **Verification**: After changing TypeScript, data schemas, or styles, run `pnpm run typecheck` and `pnpm run build` to verify both `index.html` and `404.html` emit cleanly.
